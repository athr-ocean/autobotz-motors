# D15 — Roteiro de vídeo tutorial (aprox. 3 minutos)

**Tema:** Cadastrar cliente e veículo e registrar uma venda no AutoBotz Motors
**Público:** pessoas que estão começando a utilizar o ERP
**Duração-alvo:** 3 minutos
**Importante:** gravar somente depois de conferir os nomes reais das telas e os passos na versão integrada. Usar dados fictícios.

## 0:00–0:20 — Abertura

**Narração:**

“Olá! Neste tutorial vamos acompanhar um fluxo básico do AutoBotz Motors: cadastrar um cliente, cadastrar um veículo e registrar uma venda. A ideia é mostrar a sequência de trabalho e os cuidados necessários para manter os registros corretos. Vamos utilizar apenas dados fictícios.”

**Na tela:** mostrar a aplicação inicial, ocultando qualquer informação pessoal, credenciais ou dados reais.

## 0:20–1:00 — Cadastro de cliente

**Narração:**

“Primeiro, acessamos o módulo de Clientes pela navegação da aplicação. Abrimos a opção de cadastro e preenchemos os campos solicitados. Antes de salvar, vale conferir se os dados estão corretos, porque informações inconsistentes podem dificultar as próximas operações. Depois de salvar, verificamos na consulta de clientes se o registro foi criado.”

**Na tela:** demonstrar o cadastro com dados fictícios e a confirmação real que a aplicação apresentar. Não inventar mensagens de sucesso durante a edição do vídeo.

## 1:00–1:40 — Cadastro de veículo

**Narração:**

“Em seguida, acessamos o módulo de Veículos. Preenchemos os campos obrigatórios exibidos pela versão instalada, conferimos os identificadores e salvamos. Depois, verificamos se o veículo aparece na consulta do módulo. Se houver uma mensagem de validação, devemos corrigir a informação indicada em vez de tentar contornar a regra do sistema.”

**Na tela:** demonstrar o formulário real e confirmar o registro criado.

## 1:40–2:35 — Registro de venda

**Narração:**

“Com o cliente e o veículo cadastrados, acessamos o módulo de Vendas e iniciamos o registro. Selecionamos os registros correspondentes, preenchemos os demais campos exigidos pela tela e revisamos as informações antes de confirmar. Depois de salvar, consultamos o registro de vendas para verificar se a operação foi concluída. Se a resposta demorar, não devemos enviar a mesma operação várias vezes sem antes conferir se ela já foi registrada.”

**Na tela:** mostrar o fluxo real de venda e a evidência de conclusão disponível na aplicação. Se algum passo diferir, atualizar a narração e o guia.

## 2:35–3:00 — Encerramento

**Narração:**

“Pronto! Neste fluxo, vimos como os módulos de Clientes, Veículos e Vendas se relacionam dentro do AutoBotz Motors. O principal cuidado é revisar os dados, respeitar as validações e confirmar o resultado antes de repetir uma operação. Para dúvidas, consulte o guia rápido e o FAQ do portal de treinamento. Obrigado!”

**Na tela:** mostrar o material de treinamento e encerrar sem exibir dados sensíveis.

## Checklist antes de publicar

- [ ] Os nomes das telas e ações correspondem à versão realmente gravada.
- [ ] O fluxo foi executado de ponta a ponta com dados fictícios.
- [ ] A gravação não exibe credenciais, CPF real, telefone real ou outros dados pessoais.
- [ ] A duração foi conferida e está próxima de três minutos.
- [ ] O guia rápido e o vídeo descrevem o mesmo fluxo.
